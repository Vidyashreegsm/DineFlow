# DineFlow 🍽️

A modern, responsive restaurant website built with React and TypeScript, featuring an interactive food menu, shopping cart, quantity controls, and checkout experience.

## Features

- 🍕 Food menu with category filtering
- 🛒 Interactive cart with increment and decrement controls
- 💰 Automatic cart total calculation
- 🧾 Checkout form with customer detail validation
- 🎉 Order confirmation with a demo order number
- 📱 Responsive layout for desktop and mobile
- 🎨 Warm, premium cream-and-orange design

## Tech Stack

- React
- TypeScript
- Vite
- CSS
- Lucide React

## Getting Started

### Prerequisites

Install Node.js and npm.

### Installation

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd dineflow
npm install
npm run dev
```

### Production Build

```bash
npm run build
```

## Current Limitations

Checkout currently runs as a frontend demo. Orders are not persisted to a database or sent to restaurant staff. Online payments and backend order management are not implemented.
